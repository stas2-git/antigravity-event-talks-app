# Agent Spec

## Overview

**customer-support-agent** is an ADK 2.0 graph `Workflow` that acts as a
customer support representative for **QuickShip**, a fictional shipping company.

The workflow has a two-stage design:

1. **Classify** — An `LlmAgent` reads the user's message and classifies it as
   `"shipping"` (rates, tracking, delivery, returns, lost packages) or
   `"unrelated"`.
2. **Route** — A `FunctionNode` reads the classification and sets the graph
   route, directing the workflow to one of two terminal nodes:
   - `shipping_faq_agent` — answers the question using built-in FAQ knowledge
   - `decline_node` — politely refuses and asks if there is a shipping question

## Graph Topology

```
START
  │
  ▼
classify_query (LlmAgent → ClassificationOutput)
  │
  ▼
route_query (FunctionNode → sets route)
  │
  ├─ "shipping"  → shipping_faq_agent (LlmAgent)
  │
  └─ "unrelated" → decline_node (FunctionNode)
```

## Example Use Cases

| User message | Expected path |
|---|---|
| "How much does overnight shipping cost for a 3 lb package?" | shipping_faq_agent |
| "Where is my package? Tracking: QS123456789" | shipping_faq_agent |
| "I want to return my order" | shipping_faq_agent |
| "What's the weather like today?" | decline_node |
| "Can you write me a poem?" | decline_node |
| "What are your store hours?" | decline_node |

## Tools Required

No external tool calls. All knowledge is embedded in the `shipping_faq_agent`
system instruction (rates, tracking, delivery, returns, claims).

## Constraints & Safety Rules

- The workflow must NEVER answer questions unrelated to shipping.
- The classifier must output strict JSON matching `ClassificationOutput`
  (`category` ∈ `{"shipping", "unrelated"}`, `reason` as a string).
- The `decline_node` must always redirect the user back to shipping topics.

## Success Criteria

- Shipping queries are correctly routed to `shipping_faq_agent` ≥ 95% of the time.
- Unrelated queries are correctly routed to `decline_node` ≥ 95% of the time.
- `shipping_faq_agent` responses reference QuickShip FAQ content (rates, tracking, etc.).
- `decline_node` responses are polite and invite the user to ask a shipping question.
