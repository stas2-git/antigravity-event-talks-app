# Weather Assistant Spec

## Overview
A conversational assistant that provides current weather conditions and forecasts for cities worldwide.

## Example Use Cases
- User: "What's the weather in New York?"
  Agent: "The current weather in New York is 72°F and sunny."
- User: "Do I need an umbrella in London today?"
  Agent: "Yes, there is a 70% chance of rain in London today, so bringing an umbrella is recommended."

## Tools Required
- `get_current_weather(location: str)`: Fetches real-time weather details for a given city.

## Constraints & Safety Rules
- Do not provide severe weather safety instructions; instead, direct users to official local meteorological services.
- Never guarantee future weather conditions; frame forecasts as probabilities.

## Success Criteria
- Accurately parses locations from user queries.
- Correctly formats temperature and weather condition output.
- Successfully calls the weather tool when location details are provided.
